# Входные документы

Источники, на которых строился PRD. Хранятся как есть, для истории.
Источником истины не являются — им является prd.md.

- `2026-09-09-cross-provider-skill-adapter-rnd.md` — предварительное
  исследование из репозитория prgate-kit (v0.0.5, 09.09.2026). Проектирует
  контракт адаптера: команды, пять фаз работы, структуру отчёта,
  промежуточное представление, проверку предсказуемости эталонными снимками.
  Написано до сверки с официальной документацией сред, поэтому расходится
  с ней в пяти местах — расхождения перечислены в `.memlog.md`.

- `PRD-001-legacy-autogenerated.md` — первый PRD, сгенерированный
  автоматически. Доверие к нему низкое, содержание вытеснено текущим
  документом. Оставлен, чтобы не потерять отдельные формулировки при сверке.
