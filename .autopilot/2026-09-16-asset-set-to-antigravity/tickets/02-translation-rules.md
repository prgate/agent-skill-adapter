# 02 — Правила перевода: отдельный версионируемый файл

**Требования:** R04, R13, R17, R29, R30, R31, R48
**Blocked by:** —
**Зона:** `src/agent_skill_adapter/rules.py` · `rules/` · `tests/unit/test_rules.py`
**Волна:** 1
**Status:** ready

## Что должно заработать

Появляется артефакт, который версионируется отдельно от описаний сред и объявляет всё,
что сегодня либо не существует, либо зашито в код: отображение значений полей,
отображение имён инструментов, список игнорируемого, правило по недокументированному
файлу и перечень того, к чему применяется подстановка ссылок — с явным списком
неприкосновенного.

## Из брифа, дословно

> «Таблица перевода — часть правил перевода (FR-6), версионируется отдельно от описаний
> сред, как FR-6 и требует.»
> «`__pycache__`, `.omc/`, `.pytest_cache` и подобное в перенос не попадают. Список объявлен
> в правилах перевода, а не зашит в код.»
> «`CHANGELOG.md` — история изменений, её нельзя переписывать никакими правилами подстановки,
> и правило обязано сказать, какие файлы оно трогает, а какие нет.»
> «Имя инструмента — такое же поле с закрытым набором значений, как `model`, и переводится
> тем же механизмом.»

## Разделы спецификации

Истории 9, 11, 15, 16, 17; Решения §2; Границы (`rules.py`).

## Критерии приёмки

- [ ] Файл правил читается и валидируется; свой `rules_version`, независимый от версий описаний
- [ ] `Rules.value_of(entry_id, value)` — отображение значений по id записи описания; для пары Claude Code → Antigravity `opus` и `sonnet` дают `pro`
- [ ] `Rules.tool_name(name)` — только пары, подтверждённые документацией цели (`Read`→`view_file`, `Grep`→`grep_search`, `Bash`→`run_command`); для имени без пары возвращается «пары нет», а не выдуманное имя
- [ ] `Rules.ignored(rel)` — список игнорируемого объявлен в файле; ни одного из этих имён нет в коде
- [ ] `Rules.rewritable(rel)` — перечень того, что подстановка трогает; файл истории изменений в него не входит и это закреплено тестом
- [ ] `Rules.undocumented` — одно правило на файл, которому нет места ни в одном описании
- [ ] Ни одного имени из образца `prgate-kit` в коде и в файле правил
- [ ] `make check` зелёный
