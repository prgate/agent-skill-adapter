# 07 — Ссылки ведут туда, куда легли файлы

**Требования:** R20, R31, R20.1, R20.2
**Blocked by:** 06
**Зона:** `src/agent_skill_adapter/convert.py` · `tests/unit/test_convert.py`
**Волна:** 6
**Status:** ready

## Что должно заработать

Относительная ссылка из одного перенесённого файла на другой после переезда указывает на
файл, который действительно лежит на новом месте. Переписываются только ссылки на то, что
этот прогон переместил, и только в файлах, которые названы в правилах: история изменений
не трогается ничем.

## Из брифа, дословно

> «`contexts/*.md` адресуются из субагентов относительной ссылкой (`../contexts/review.md`) —
> после переезда ссылка обязана указывать на файл, который действительно лежит на новом
> месте, иначе получится роль, отправляющая себя в несуществующий режим.»
> «`CHANGELOG.md` — история изменений, её нельзя переписывать никакими правилами подстановки.»

## Разделы спецификации

Истории 13, 17, 37, 38; Решения §7.

## Критерии приёмки

- [ ] Ссылка на перемещённый файл переписана под его новое место
- [ ] Ссылка на файл, оставшийся на месте, не тронута
- [ ] Ссылка наружу набора не переписывается и получает строку отчёта
- [ ] Файл истории изменений совпадает с исходным байт в байт — закреплено тестом
- [ ] Каждая применённая подстановка видна в отчёте
- [ ] `make check` зелёный
