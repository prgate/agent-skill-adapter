# 08 — `--install`: сборка в живой корень с планом до первой записи

**Требования:** R50i, G01, R01, R25, R27, R50i.1, R50i.2, R50i.3
**Blocked by:** 07
**Зона:** `src/agent_skill_adapter/convert.py` · `src/agent_skill_adapter/cli/main.py` · `tests/unit/test_convert.py`
**Волна:** 7
**Status:** ready

## Что должно заработать

Разрыв «лежит на диске» — «работает в среде» закрывается: по умолчанию сборка идёт в `--out`
и команда печатает готовую строку установки; по явному `--install` те же назначения
раскрываются относительно живых корней целевой среды, план печатается до первой записи,
и действуют те же проверки коллизий и выхода за корень.

## Из брифа, дословно

> «конвертировать произвольный набор скиллов формата Claude Code в рабочее состояние в среде
> Antigravity (корень `~/.gemini/`)»

Ответ пользователя (Дополнения, 2026-09-16): «--out + явный --install». Живой корень
трогается только по флагу, с показом плана до первой записи.

## Разделы спецификации

Истории 18, 39–41; Решения §6.

## Критерии приёмки

- [ ] **Состав задаётся из командной строки.** Повторяемые опции `--skills DIR`, `--agents DIR`, `--commands DIR`, `--rules PATH`, `--plugin FILE` (Решения §3). Без них человек состав задать не может: модульная половина готова с таска 03, а до сих пор ни один таск опций не брал
- [ ] Позиционный аргумент «одна папка скилла» продолжает значить ровно то же, что и раньше
- [ ] Без `--install` живой корень не трогается ничем; печатается готовая команда установки
- [ ] С `--install` назначения раскрываются относительно корней, которые называет описание цели; ни один путь не вписан в код
- [ ] План печатается до первой записи — всегда, а не по отдельному флагу
- [ ] `--install` вместе с `--out` — отказ с объяснением
- [ ] Путь, выходящий за пределы корней цели, — отказ, как сегодня для `--out`
- [ ] Повторный `--install` показывает, что будет заменено, и не сносит чужое молча
- [ ] Опция, называющая другой файл правил, есть; сломанный файл правил даёт отказ с отчётом, а не трассировку в терминал
- [ ] `make check` зелёный
