# 04 — Сводный отчёт по набору и честная строка происхождения

**Требования:** R26, R03, R09, R10, R23, R24, R26.1, R30, R05
**Blocked by:** 03
**Зона:** `src/agent_skill_adapter/convert.py` · `src/agent_skill_adapter/cli/main.py` (только чтобы команда продолжала работать) · `tests/unit/test_convert.py`
**Волна:** 3
**Status:** ready

## Что должно заработать

`convert` принимает набор целиком, спрашивает описания про каждую сущность и печатает
один отчёт с одним вердиктом — худшим по набору. Ни один файл не исчезает и не ложится
без строки. Строка «нет записи ни в одном описании» перестаёт печататься там, где запись
знает цель: это разные случаи и разные строки.

## Из брифа, дословно

> «Отчёт — сводный по всему набору, вердикт прогона — худший по нему, как сейчас внутри
> одного скилла.»
> «Строка «нет записи ни в одном описании» сейчас печатается и тогда, когда запись знает
> цель, а не знает источник. Два разных случая — две разные строки.»
> «Ни один файл кита не должен ни исчезнуть, ни лечь на диск неработающим без строки в отчёте.»
