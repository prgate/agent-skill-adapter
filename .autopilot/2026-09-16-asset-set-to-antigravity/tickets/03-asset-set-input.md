# 03 — Вход конвертера: набор ассетов, а не одна папка

**Требования:** R04, R25, R27, R07, R05, R25.1, R25.2, R25.3, R29
**Blocked by:** 02
**Зона:** `src/agent_skill_adapter/assets.py` · `tests/unit/test_assets.py`
**Волна:** 2
**Status:** ready

## Что должно заработать

Конвертер читает набор, заданный составом: папка скиллов, папка субагентов, папка команд,
файлы правил, манифест плагина. Любая часть может отсутствовать. Набор, разложенный иначе,
чем образец, читается теми же правилами — раскладка одного репозитория ничего не решает.

## Из брифа, дословно

> «Цель требует входа «набор ассетов»: папка скиллов, папка субагентов, папка команд,
> файлы правил, манифест плагина — каждая часть необязательна, набор без субагентов
> конвертируется так же спокойно, как набор с ними.»
> «Вход задаётся составом, а не одним корнем: набор, разложенный иначе, чем prgate-kit,
> должен конвертироваться теми же правилами.»
> «Имя, которое никто не документировал, становится строкой `unknown`/`extension` в отчёте,
> а не исчезает и не получает особую обработку.»

## Разделы спецификации

Истории 2, 4, 5, 29–31; Решения §3 и §4; Границы (`assets.py`).

## Критерии приёмки

- [ ] `read(Inputs) -> tuple[Asset, ...]`; вид сущности — скилл, субагент, команда, файл правил, манифест
- [ ] Каждая сущность несёт id записей, про которые спрашивает описания; список известных имён в коде не заводится
- [ ] Набор без субагентов читается так же спокойно, как с ними
- [ ] Названная папка существует и пуста — не ошибка; это отражается в результате чтения
- [ ] Названной папки нет — отказ с путём, без трассировки
- [ ] Состав не задан ни одной опцией — отказ, называющий, чего не хватает
- [ ] Игнорируемое (по правилам из таска 02) отсеивается при чтении и остаётся видимым: пропущенный путь не исчезает молча
- [ ] `make check` зелёный
