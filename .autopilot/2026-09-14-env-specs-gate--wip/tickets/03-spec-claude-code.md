## Что должно заработать

Файл `specs/anthropic/claude-code-2.1.yaml` — описание исходной среды по официальной документации.

Источник — `https://code.claude.com/docs/en/*`. У документации есть markdown-версия страницы:
к любому адресу добавляется `.md` (`…/docs/en/skills.md`), и полный список страниц лежит в
`https://code.claude.com/docs/llms.txt`. Хеш считается по markdown-версии — так задано
правилом нормализации (`normalization: v1`, модуль `envspec.normalize` из таска 01).
Загружать страницы: `curl -sS --compressed -A "Mozilla/5.0" -L`.

Что должно попасть в `capabilities` (это перечень тем, а не готовый ответ — что именно
поддерживается, решает документация):

- поля frontmatter скилла: `name`, `description`, `allowed-tools`, `model`, `context`, `agent`,
  `arguments`, `disable-model-invocation`, `hooks`, `effort` и остальные, какие найдутся
  (`kind: skill-field`);
- субагенты `.claude/agents/*.md` и их поля — `permissionMode`, `maxTurns`, `isolation`,
  `mcpServers`, `tools`, `model` (`kind: subagent-field`);
- события hooks из `settings.json` — `PreToolUse`, `PostToolUse`, `SessionStart`,
  `UserPromptSubmit` и остальные (`kind: hook-event`);
- виды файлов настроек, участвующие в переносе (`kind: settings-file`).

Плюс `limits:` (пределы размера, если документация их называет — с явной единицей) и
`invisible_sources:` — настройки, которые лежат вне репозитория и адаптер их не увидит
(например, hooks уровня пользователя из `~/.claude/settings.json`).

**Версия среды:** локально установлен Claude Code 2.1.270, `version_range` — `">=2.1.0,<2.2.0"`.
PRD называет привязку полей к версиям (`background` с v2.1.218, `maxTurns` с v2.1.246) —
если документация подтверждает, это идёт в `note` записи.

**Чего не делать:** не выдумывать. Свойство, о котором документация молчит, либо не попадает
в описание вовсе, либо получает `support: unknown` с честным `note`. Придуманная запись
со ссылкой — худший возможный результат этого таска.

## Критерии приёмки

- [ ] `envspec.loader.load()` читает файл без ошибок схемы
- [ ] У каждого источника заполнены `url`, `markdown_url`, `anchor`, `sha256`, `checked_at`,
      `environment_version`; `sha256` совпадает с `digest(normalize(section_text(...)))` от живой страницы
- [ ] Каждая `capability` ссылается на существующий `source_id`
- [ ] Покрыты все четыре вида: `skill-field`, `subagent-field`, `hook-event`, `settings-file`
- [ ] `invisible_sources` содержит хотя бы настройки уровня пользователя, со ссылкой на раздел документации
- [ ] Ни одной записи без источника
- [ ] Заполнен `layout:` — где среда держит скиллы, субагентов, настройки и hooks
- [ ] В `capabilities` присутствуют **все** поля frontmatter скилла, которые называет документация
      (PRD говорит о восемнадцати сверх `name`/`description`), все поля субагентов и все события hooks.
      Неполный перечень делает перечень пробелов из таска 05 бессмысленным
