## Что должно заработать

`envspec.freshness.check(spec, fetch=...) -> list[Discrepancy]`: для каждого источника описания
заново загружается markdown-версия страницы, вырезается раздел по `anchor`, считается хеш по
правилу `normalization: v1` и сравнивается с записанным `sha256`.

- Хеши разошлись → расхождение `changed` с обоими хешами и датой.
- Страница недоступна, код ответа не 200, раздела с таким `anchor` больше нет → расхождение
  `unreachable`. Это именно расхождение, а не подтверждение актуальности.
- Совпало → ничего.

`record(path, discrepancies)` дописывает найденное в секцию `discrepancies:` самого файла описания,
сохраняя остальной YAML читаемым. Смысл — чтобы локальный запуск без сети видел устаревание
по файлу, а не по журналу CI.

Запуск — `python -m agent_skill_adapter.envspec.freshness [--write]`: без `--write` только печатает,
с `--write` записывает в файлы описаний. Сеть — `urllib` из стандартной библиотеки, с тем же
User-Agent, что в тасках 03–04. **Это единственный модуль проекта, которому разрешена сеть.**

Тесты сети не касаются: `fetch` подставляется параметром.

Cron-workflow в GitHub Actions и автоматический PR (FR-10, FR-8 в части PR) — вне этого прогона,
решение заказчика: «PR-бот потом». Не делать.

## Из брифа, дословно

> «По расписанию в CI проверяется, изменилась ли документация поставщика: для каждой записи
> заново загружается её раздел и сравнивается хеш нормализованного текста» (FR-7)
> «Значимым считается изменение содержания раздела, а не оформления страницы» (FR-7)
> «Недоступность источника — тоже расхождение, а не подтверждение актуальности» (FR-7)
> «Найденное расхождение записывается в сам файл описания и попадает в репозиторий…
> локальный запуск без сети обязан его видеть» (FR-8)

## Критерии приёмки

- [ ] Изменившийся текст раздела даёт расхождение `changed` с обоими хешами
- [ ] Изменение только оформления (пустые строки, хвостовые пробелы, `\r\n`) расхождения не даёт
- [ ] Ошибка `fetch` и код ответа не 200 дают `unreachable`, а не пустой результат
- [ ] Исчезнувший `anchor` даёт `unreachable`
- [ ] `record()` дописывает `discrepancies` в файл; `load()` после этого читает файл без ошибок,
      а `is_stale()` возвращает True
- [ ] В тестах нет ни одного сетевого вызова
- [ ] `make check` зелёный
