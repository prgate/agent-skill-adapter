## 1. `shutil.Error` при сборке папки

> `shutil.copytree()` collects child-copy failures, including a dangling symlink, and raises
> `shutil.Error`. `_assemble()` catches only `OSError`, and `convert()` also does not catch
> `shutil.Error`. A directory part with a dangling symlink therefore bypasses cleanup and the
> machine-readable refusal report.

## 2. Коллизия ключей после нормализации

> A YAML date key and an equivalent quoted string key are distinct before this conversion but
> both become the same string key here. For example, `2026-09-14:` and `"2026-09-14":` under
> a reproduced hook mapping cause one value to overwrite the other before `hooks.json` is
> written. Normalize mapping keys into a temporary mapping and refuse duplicate normalized
> keys. Add a regression test for this input.

## 3. Гонка при записи (TOCTOU)

> **Path Traversal** · CWE-367 Time-of-check Time-of-use
> `_assemble()` resolves each staged path before creating parent directories or writing files.
> A concurrent writer can replace a checked path component with a symlink, causing `mkdir()`
> or subsequent writes to escape `out`. Staging under `out` does not prevent this race.
> Reject symlinks during every destination-path operation.

## 4. Пересекающиеся места назначения

> The preflight only detects paths that existed before assembly. It does not detect two
> planned parts that expand to the same staged path. `EnvSpec` requires unique layout IDs,
> not unique layout paths, so a target can map `skill.file` and `skill.top.README.md` to one
> file. The later `copy2` overwrites the earlier file, while `written` reports both as
> successful. Validate that planned staged paths are unique and do not overlap before the
> write loop. Return `COLLISION` when they do.

## Что уже проверено запуском до начала работы

  код 7, отчёт, ноль файлов под `--out` и ноль трассировок.
- Находка 2 **подтверждается**: скилл с ключами `2026-09-14:` и `"2026-09-14":` под

  Значение `from-date-key` исчезло молча — отчёт про потерю не сказал ничего.
